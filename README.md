#  IPL Win Prediction System

A Machine Learning-based IPL match prediction system that predicts the winning probability of teams using live match data such as:

* Current Run Rate (CRR)
* Required Run Rate (RRR)
* Runs & Balls Remaining
* Wickets Left
* Target Score
* Past Match History

The project includes interactive charts, analytics, and real-time prediction visualization.

---

##  Features

* Live win probability prediction
* Interactive charts & graphs
* Match analytics dashboard
* Historical data analysis
* ML model training & evaluation

---

##  Tech Stack

* Python
* Pandas
* Scikit-learn
* React.js
* Tailwind CSS
* Matplotlib / Seaborn

---

##  ML Models Used

* Logistic Regression
* Random Forest
* XGBoost

---

##  Goal

To analyze IPL match situations and predict winning chances using Machine Learning and Data Analytics.
